# SistemaRural-PE

## Descripción
SistemaRural-PE es un prototipo de software desarrollado en Python para gestionar establecimientos de salud rurales del Perú.

## Objetivo
Facilitar el registro de pacientes, programación de citas médicas, registro de atenciones y generación de reportes estadísticos.

## Tecnologías utilizadas
- Python 3.x
- Tkinter
- Git y GitHub

## Paradigmas aplicados
- Programación estructurada.
- Programación orientada a objetos.
- Programación funcional.
- Programación orientada a eventos.

## Módulos
1. Pacientes.
2. Citas médicas.
3. Atenciones.
4. Reportes.
5. Usuarios.
6. Cerrar sesión.

## Ejecución
Ejecutar el siguiente comando:

```bash
python SistemaRural_PE.py
```
